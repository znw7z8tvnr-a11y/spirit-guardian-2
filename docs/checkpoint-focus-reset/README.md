# 獨立優化：背景中斷取消清除存檔確認

checkpoint_view.gd 原先只在隱藏、換紀錄或繼續遊戲時取消清除確認。現在視窗／應用失焦或應用暫停，也重設已進入第二步的確認與時間門檻，並取消兩個按鈕的殘留按壓。回到遊戲後第一次點清除，只會重新進入確認，仍須第二次明確操作；不改變 350ms 防連點門檻。

不修改存檔內容、格式、備份、獎勵或繼續遊戲機制。確認狀態不是存檔的一部分。只有完成既有第二次確認時才發出清除請求。

Godot 4.6.3 匯入及 Lab 解析通過，checkpoint 44／touch 20，共 64 項相關引擎檢查通過；Python 選測規則 27 項通過。新增獨立訊號接收器覆蓋三種中斷、已超過時間門檻的確認、返回第一次點擊及正常兩步清除。測試核對中斷前後實際存檔位元組相同。初次新增測試誤用了「繼續遊戲之前」的檔案作基準；續玩本來會更新保存資料，修正為測試中斷前的快照後通過，未為通過測試改動存檔程式。

Web 增加真實觸控清除提示、window blur／canvas focus、返回一次點擊保留 localStorage 原字串，最後正常確認可清除；失焦事件是瀏覽器測試模擬，不代表 iPad 切 App 真機測試。完整瀏覽器結果及交付資料另記。本輪不重跑 20 波或所有技能；線上試玩站與原 HTML 保留，美術仍為暫用。

Chromium 橫直向各九項存檔流程通過，包含新增的焦點中斷取消確認、真實第三波續玩、裝配保存、損壞主檔回退及儲存故障顯示，無頁面／引擎錯誤（browser/）。截圖為實際遊戲。完整專案包入口為 Lab，通過 CRC、來源檔案逐一對照、乾淨匯入及 600 幀啟動；大小與 SHA256 見 project-zip.json。
