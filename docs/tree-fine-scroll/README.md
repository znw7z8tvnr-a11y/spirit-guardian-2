# 獨立優化：連鎖樹細幅觸控捲動

延續背包的細幅捲動修正，在 tree_view.gd 對單一拖曳累積小數位移。四次 0.25 邏輯像素會產生一個實際捲動像素，反向移動互相抵消；到達上下邊界後，超出範圍的移動不累積為拖曳負債。

沿用 12 像素拖曳門檻、第二指不得接管、拖曳取消節點按壓及遮罩阻擋。放手、失焦、應用暫停、隱藏或重建樹時清除小數；不改變節點大小、配置、分岔規則、物品或亂數，也不增加慣性捲動。上一批背包與獎勵卡優化保留，沒有回退到舊整合版。

Godot 4.6.3 匯入、Lab 解析及 tree 84／inventory 44／inventoryfilters 35／touch 20，共 183 項相關檢查通過；Python 選測規則 27 項通過。新增測試以實際 ScrollContainer 驗證四次小數位移、反向返回、上下邊界與失焦清除小數，既有節點重用、遮罩、配置與背包回歸保留。小數輸入由 Godot 測試事件提供，不當成 iPad 硬體驗收。
