# 每三波獎勵與 Boss 結算試玩

## 本輪實作

清除第 3、6、9、12、15、18 波後，技能／寶石／詞條各一個隨機候選，三選一。普通波每次選擇有一次免費刷新，刷新重新抽出三類候選，不消耗背包物品，也可能再次出現相同候選。固定類別覆蓋是本輪的保底，不另宣稱已有完整稀有度保底。

Boss 擊破後標記，待該波敵人清空、剩餘連鎖結束、血肉收集完成，再追加 1～5 次選擇；第 15 波會與三波獎勵相加。第 20 波先結算 Boss 獎勵，再完成本局，不產生第 21 波。同一波只結算一次。

選擇期間暫停戰鬥、怪物、投射物及下一波；每選一項消耗一次機會，全部領完才繼續。技能／寶石以獨立編號加入圖示背包，不自動裝備。詞條當局生效，重開清除：

- 再啟靈思：之後每次選擇多一次刷新，可疊加。
- 靈能增幅：每層增加 10% 詞條法術倍率，與血肉倍率相乘。背包比較使用相同公式。

技能目前仍為奧彈、火、冰、雷四類，1～3 級；寶石為接續寶石，三級可分岔。技能等級暫定 70%／25%／5%，寶石暫定 70%／22.5%／7.5%。Boss 次數均勻抽選 1～5。此為試玩調校，尚未完成全原版 22 攻擊技能及 19 寶石移植。

正常獎勵物品可使用隨機排列；已發現配方可使用持有物品排列，不會偷補試驗物品。若無法組出配方會保留配置。只有寶石、沒有後續技能時維持開局快攻，避免首個寶石降低輸出。試驗配置的物品編號與實戰獎勵分開，重複載入不重複發物品。

## 檔案與驗證

- rewards.gd：獨立當局獎勵狀態、候選、刷新與詞條。
- reward_view.gd：觸控選擇與刷新介面。
- main.gd：清場結算、暫停、背包入庫、攻擊倍率。
- chain.gd：以實際持有物品排列、試驗套裝編號與連鎖快攻判定。
- tests/wave_rewards.gd：結算冪等、Boss 範圍、詞條、物品與場景整合；保留其餘回歸測試。
- docs/rewards/：本輪引擎、正式 Web 封裝、實際遊戲截圖、線上完整性與 GitHub 建置證據。
