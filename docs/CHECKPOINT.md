# 波間存檔與續玩（試驗版）

完成一波、敵人／飛行法術／連鎖／待吸收血肉全部結清後，自動保存最近的安全波間。重新整理頁面後，先顯示「繼續波間進度」與「重新開局」，不直接開戰。

保存波次、核心與血肉城牆、本局成長、技能／寶石及十格連線、已領與未領獎勵、剩餘刷新次數、倍速／節奏、冷卻、召喚物與四組亂數狀態。領獎、刷新與配置變更會更新安全波間；重載不重領獎勵、不補回刷新。召喚物保留原傷害與剩餘壽命，不重套增幅。

## 儲存方式

Web 的小型波間資料使用同步 `localStorage` 並立即讀回核對，成功後才顯示已保存；獨立鍵為 `sg_chain_lab_run_v1` 與 `.bak`。先前未發布的非同步檔案原型曾在雲端讀回較舊配置，因此不採用延遲補寫作為正式方案。

原生版使用 `user://chain_lab_run_v1.json`、上一份備份與暫存檔，驗證後原子更名。共用格式版本、SHA-256、型別、有限數值、獎勵來源與節點圖檢查；整份通過才讀回。檢查碼偵測損壞，不是防作弊服務。主檔損壞可回退較早備份；無法辨識版本保留至明確重新開局。

原版 HTML、M2 舊配置與共振紀錄書不混用。本局清除只刪除續玩資料；共振發現依原保存規則獨立處理，讀回時合併已發現配方。

## 範圍與限制

- 戰鬥中中斷回到最近波間；第一波尚未完成時沒有續玩點。不是即時戰鬥快照。
- 訓練／試驗配置不覆寫正常局進度；明確重新開局及正常局勝負結算會清除本局進度。
- 一份本機進度與上一份備份，無雲端同步。同來源多分頁共用此進度，請避免同時進行兩局。
- 換瀏覽器、換網址、清除網站資料或瀏覽器回收儲存空間都可能無法續玩；容量不足、存取遭拒會顯示失敗，不冒稱保存成功。不保證突然斷電後的資料持久性。
- Linux Chromium 觸控模擬不是 iPad Safari 實機驗收；美術仍為暫用，未宣稱完整原版功能或最終難度完成。

## 修改與驗證

`checkpoint_store.gd`：資料驗證與兩種保存後端；`checkpoint_view.gd`：續玩介面；`main.gd`：安全波間與 UI。既有測試停用持久續玩，避免測試局互相污染。

原生 38 組測試共 1,300 項通過，含實際第三波、刷新／領獎、場景重載、四組亂數下一次抽值、召喚物傷害與壽命、損壞資料與備份。補充三種實際二十波獎勵策略，60 個波間資料全通過驗證、三局均通關；補充檢查不混入 1,300 項計數。

Web `test_checkpoint_web.py` 使用真實觸控與近即時重載，直接核對儲存的配置，測試刷新不回復、獎勵不重發、裝配保留、主檔損壞回退、容量不足與存取遭拒。儲存故障是測試對瀏覽器 API 的模擬，沒有注入遊戲物品或戰鬥狀態。

技能回歸切換測試局時會實際重載頁面；若出現續玩提示，再觸控重新開局，避免獎勵視窗擋住戰鬥區按鈕。

目前有效報告為 `browser-synchronous.json`、最新 `browser-staged.json` 與後續 `release.json`。`browser-web.json` 為已淘汰非同步原型的歷史報告，不作最終驗收。截圖為實際遊戲；完整雲端回歸與發布結果以交付紀錄為準。
