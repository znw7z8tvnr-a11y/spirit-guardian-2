# 第十種 Lab 攻擊：土刺

保留 V9 土刺基礎傷害 29、落點距離嚴格小於 75、最多 24 個目標的規則。目標優先，其餘按距離排序，是明確的選敵調整。沒有額外暈眩、擊退或持續傷害。等級一至三級、血肉與詞條倍率沿用共用傷害公式。

目標消失仍在原落點結算；沒有受擊者算落空。多目標只推進一次連鎖，條件寶石使用真實命中結果。Lab 獎勵、背包與技能演練納入土刺，演練提供二級；預設連鎖保持原配置，從背包替換即可使用。

新增自行製作的分層岩刺 SVG Sprite，呈現冒出與淡出動畫。素材是暫用，尚未達最終美術品質。背包每頁最多十五張卡片，新增上一頁／下一頁按鈕，避免卡片增加後超出畫面；不刪除物品或增加連鎖格數。

穩定根目錄仍維持八種攻擊，Lab 為十種。原版二十二種中仍有十二種尚待移植；十九種寶石仍有十種尚待移植。完整原版行為對照、二十波平衡、iPad Safari 實機與正式美術均未完成驗收。
