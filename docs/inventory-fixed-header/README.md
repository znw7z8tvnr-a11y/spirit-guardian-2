# 背包操作列與物品捲動

Lab 背包的返回、確認、比較說明、分類與換頁操作留在上方；下方物品區獨立捲動。換頁時物品區回到頂端，保留既有翻頁取消隱藏候選、關閉取消預選及實體物品驗證。極小畫面若連操作區也放不下，外層捲動仍可使用，避免內容被裁掉。

修改 inventory_view.gd、inventory_ui.gd 與 test_inventory_filters_web.py，沒有改動戰鬥數值、物品數、取得順序、連線、存檔、字型或原 HTML。
