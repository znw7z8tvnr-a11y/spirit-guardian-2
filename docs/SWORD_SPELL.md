# 第十二種 Lab 攻擊：迴旋月刃

核對 V9 寶石模組、V31.16 法術模組與 V31.30 戰鬥特效模組：sword 基礎威力 26，落點距離嚴格小於 110，最多 24 個目標；實際傷害派送把 sword 映射為 fire。V31.16／V31.30 的視覺演出使用三把旋轉刀刃，並非三次命中。

本次接入 Lab 一至三級獎勵、背包預覽、替換、技能演練與連鎖。演練提供二級月刃。每次施放只結算一次範圍傷害，動畫旋轉不新增傷害或連鎖事件。目標消失仍保留原落點，無受擊者算落空。命中結果以火元素進入本輪連鎖與條件寶石；並非新增一套共振配方。

選敵沿用 Lab 的選中目標優先、其餘按距離排序，是明確的選敵順序調整。沒有新增回程傷害、吸引、擊退或持續傷害。原版既有倍率的全面對照與完整模組行為仍待驗收，不能因為本技能可玩而宣稱全量移植完成。

新增自行製作的暫用月刃 SVG Sprite，投射期間旋轉，落點由三把月刃繞行並淡出。這是暫用美術，尚未達最終 2.5D 品質。最多四十八組特效，每組月刃三個子 Sprite；不宣稱已做 iPad 效能驗收。

背包每頁仍最多十五張卡，演練二十二件物品全部保留，連鎖仍為十格。點「技能演練」後，從背包第二頁選月刃替換。穩定版根目錄仍維持八種攻擊；Lab 為十二種暫行攻擊，原二十二種尚有十種待移植，十九種寶石仍有十種待移植。完整二十波平衡、正式美術、iPad Safari 實機驗收尚未完成。

寶石相容性的明確差異：原 V9 灼燒條件用 `context.kind===fire`，因此原碼中的 sword 不會符合該條件；本 Lab 延續既有的實際命中元素快照設計，月刃造成火系傷害，所以可符合灼燒觸發。這是本版系統整合選擇，不是逐位還原舊寶石判定。

本機驗證：639 項 Godot 4.6.3 引擎檢查全部通過，其中月刃二十二項涵蓋真實傷害、嚴格半徑邊界、二十四目標上限、火系寶石條件、單次連鎖延伸、飛行旋轉、三個月刃子 Sprite、目標消失後原落點命中與落空。

完整瀏覽器連鎖演練在橫向、直向皆通過；另從正常頁面重新載入後，透過背包裝備月刃，兩向各施放一次並命中一次，沒有頁面或引擎錯誤。上線包另外使用分段 WASM 載入器，兩向都成功裝備月刃為起始技能、造成傷害，並在月刃 Sprite 還存在時暫停。sword-package 截圖為實際遊戲畫面，並非概念圖，暫用素材仍未作正式品質驗收。

上線包額外測試第一次因測試腳本中的 window 名稱誤植而停止，修正腳本後已完整通過；沒有為此修改遊戲行為。Linux Chromium 軟體 WebGL 的測試結果不能替代 iPad Safari 實機效能驗收。
