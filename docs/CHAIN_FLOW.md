# P1 第一批：跳怪、空放與施放共振

分支：godot/p1-chain-flow。此批只更新獨立 /lab/ 試驗室，原HTML、main、M2.1根入口保留。

## 範圍

依計畫先處理連鎖判定差距，不把來源22種技能、19種寶石及50組共振資料冒充完整實作。Lab仍使用4種技能與試驗物品；肉／城牆分配、雙杖與完整獎勵未在本批擅自定案。

## 規則改變

- 接續優先搜尋上一落點480世界單位內、本輪尚未選過的活怪。即使A還活著，也能A→B→C。
- 同輪分岔即時預留目標，優先分開；只剩一隻活怪時可繼續攻擊牠，不讓Boss場景失效。
- 每條支線保存自己的上一落點，不再共用容易被另一支線覆寫的發射起點。
- 原目標死亡或釋放時，保留已啟動連鎖。無近怪時仍施放到最後落點，有法術、命中特效與空放紀錄。
- 施放型接續可在落空後繼續；命中、擊殺、暴擊等條件不得由空放偽造。元件處理不等於完整還原來源19種寶石。
- 等待中的下一段會重新找怪；新怪進入附近時可接回，仍不跨整張地圖搜尋。
- 共振在技能實際建立／施放後累積元素，而非等待命中。未觸發、未連通、背包物品不算。分岔共用當輪元素，每輪一次判定與既有試驗冷卻保留。
- 無怪時不開新一輪；當輪可空放完成。複數受害者只推進一次後續，回呼重複或舊輪次回呼不得複製事件。
- 修正目標在飛行途中被釋放時的lambda捕捉錯誤，改用WeakRef。

搜尋策略、480距離、接續機率、30%共振率、8秒冷卻及一輪限制仍是試驗設定，不宣稱已完成正式平衡或所有長鏈詞條。

## 可觀察資訊

HUD顯示跳躍與落空次數；debug=1時提供有限長度事件紀錄，包含輪次、節點、目標、發射起點、落點、命中／落空與寶石判定。不是公開命名的可信後端。

測試用seed只在debug=1且指定正數seed時生效；正常遊戲維持隨機。測試不證明正常隨機局的20波平衡。
