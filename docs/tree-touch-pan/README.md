# 獨立優化批次：連鎖樹觸控捲動

Lab 連鎖樹支援在節點區垂直拖曳外層捲動容器，超過 12 邏輯像素才視為拖曳；小幅移動仍保留一般點選。拖曳成立時取消節點按壓，放開不會誤選節點。只由起始手指控制，放開、隱藏或重新建立視圖後清除手勢。

觸控起點必須在樹與容器可見範圍內，並檢查祖先分支上蓋住此區的後置阻擋 Control。背包等既有同層面板顯示時，不處理背後樹的拖曳；這是現有 UI 階層的遮擋保護，不宣稱通用跨視窗命中測試。

不新增／移除連線、不修改配置、物品、亂數、傷害、波次或存檔；沒有新增橫向捲動或慣性捲動。橫向短畫面內容溢出時會捲動，直向能完整容納內容時可以保持原位，但拖曳仍不得選中節點。

修改 tree_view.gd、chain_tree.gd、兩份瀏覽器測試與局部驗收依賴；test_chain_lab_web.py 新增可指定報告目錄，原本預設入口與完整短戰鬥驗收保留。

Godot 4.6.3 匯入、Lab 解析與 tree 67／inventory 25／inventoryfilters 27／touch 20，共 139 項相關檢查通過；Python 選測與錯誤處理 24 項通過。新增測試覆蓋小幅移動、第二指、捲動不選節點、放開結束、模型／RNG 不變、蓋住樹的面板、隱藏與重建取消手勢。

Web 結果以 browser-tree/tree-editor-web.json 與 browser-inventory/browser-tree-overlay.json 為準，未產生報告前不能當成通過。本地樹測試用 editor-only 短流程，測拖曳／返回、正常點選、圖示背包預覽與替換、連線拒絕與隨機配置；背包測試另驗證拖曳背包時，背景樹節點位置不變。兩份測試各自跑橫直向，單機順序執行。

獨立保存本批，不移動既有版本標記，不更新線上站。未跑完整 20 波或全部技能，未測 iPad Safari 實機；美術仍為暫用，截圖均為實際遊戲。
