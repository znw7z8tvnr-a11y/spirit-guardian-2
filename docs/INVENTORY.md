# 圖示背包與替換比較

獨立 Chain Lab 新增圖示背包。配置頁點選節點，再按「圖示背包／比較」或「替換此格」。可查看本局所有持有物品、等級與裝備位置，點選候選後比較，確認才生效；返回會取消。

顯示直擊基礎傷害（等級與血肉攻擊加成）、寶石可接線數。傷害預覽不等於總 DPS，範圍、敵方抗性與狀態效果另計。使用與實際施法相同公式。

不相容連線、占用物品、根技能清空或降級破壞分岔時，先顯示具體原因並停用確認。ChainGraph 的共用純驗證函式同時供預覽與裝備使用，拒絕時保留攻擊佇列與物品。

開局仍只有奧彈；「載入試驗配置」提供測試物品，不代表正式每三波獎勵已完成。維持十格容量、共振探索與原戰鬥規則。圖示仍為暫用美術，未加入拖放。
