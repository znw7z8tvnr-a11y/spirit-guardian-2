# 二十波戰局與勝敗結算（Lab）

本輪補上明確勝敗狀態、唯讀結算、重新開始及完整戰局驗收，沒有調整怪物或玩家戰鬥數值。原 HTML、穩定 M2 入口維持原樣。

## 結算規則

勝利必須在第20波、四個首領已擊敗、20波清除紀錄齊全、場上沒有敵人或未完成連鎖、最終獎勵已領完且裝配已確認後成立。最後首領仍保留1～5項獎勵，計入當局統計，不默默刪掉或轉成下一局戰力。核心實際歸零才會敗北，演練模式敗北另有明確標記。

結算記錄到達及完成波次、遊戲時間、擊殺與首領、施放／命中招數／落空招數、跳怪、共振、暴擊受擊者、吸收血肉、獎勵選擇與技能寶石數、生命及四項血肉成長。一次完成後不可重複結算，畫面使用複製資料，不發放新物品或永久戰力。

重新開始實際重新載入場景，回到奧彈一招、10格、100核心／360城牆、零血肉、零當局成長與獎勵紀錄、1倍速。既有共振紀錄書沿用原保存規則。本輪沒有新增永久戰局歷史、排行榜或正式成就系統。

## 實測範圍

引擎測試包含三個固定種子、不同獎勵選擇策略、從正常奧彈開局到二十波與四首領、逐波狀態、全程最低城牆及核心、敵人峰值、最終獎勵不重領、真實死亡與場景重載。舊有末波單元測試補齊已完成19波與已擊敗首領的前置資料；另有測試確認直接跳到20不能假造通關。

瀏覽器測試用實際觸控領獎、隨機排列、確認裝配與8倍速，從一般開局完成20波，再檢查勝利結算與重開；敗北畫面來自獨立且明確標示的四十隻敵人演練，不把演練當成正常通關。沒有 JavaScript 注入遊戲狀態。

初步三個種子都能通關，核心未損；數據只證明這些選擇策略可玩，不能代表所有隨機配置或最終難度已平衡。逐波與最低防線數據見本輪報告目錄，後續平衡應據此擴充樣本，不一律削弱前期。

素材仍為暫用；Linux Chromium 觸控模擬不代表 iPad Safari 實機，原版全部特殊詞條與50組共振效果也未因此宣稱完成。
