# 獨立優化：荊棘特效高度分組

thorn_fx.gd 將固定寬度移到建立時設定，八根尖刺依原本三種生長倍率分組。更新時只計算三組高度／下限，不再逐根重算固定寬度與倍率。分組只保存這個有限壽命特效的八根尖刺引用，特效釋放時一起釋放；不增加跨場景快取。

保留原圖檔、八根尖刺的地面位置、偏移、大小曲線、淡出及一秒壽命。沒有改動技能傷害、半徑、選敵、連鎖或存檔，也沒有增加持續傷害或永久城牆。這是消除固定計算，沒有量測實機 FPS 增幅。

Godot 4.6.3 匯入及 Lab 解析通過，thorn 30／orbit 29／chainlab 30／touch 20，共 109 項相關引擎檢查通過；Python 選測規則 31 項通過。129 個時間點×8 根，共 1,032 個樣本對照舊公式，縮放誤差小於 0.000001，並核對位置、偏移與淡出。另驗證同時兩個特效不共用可變分組／動畫狀態、真實暫停與恢復；既有單次傷害、落空、有限壽命及連鎖檢查保留。補上雙特效檢查後只重跑 thorn，其餘程式與先前測試相同，不重複累加檢查數。

將既有旋轉法球 Web 流程加上 --spell 參數，荊棘以薄包裝共用實際觸控／暫停／清除驗收，避免複製整套測試。兩種法術都會在本批重新跑橫直向局部回歸，沒有重跑全部技能或整局。結果與交付資訊另記。美術仍為暫用，iPad Safari 尚未實測，線上試玩站、原 HTML 與舊版本標記保留。
