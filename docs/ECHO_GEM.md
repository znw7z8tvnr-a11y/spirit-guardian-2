# 迴響寶石：依原版說明重製

來源 V9 的 `echo` 說明為「後續技能再施放機率 20%／35%／50%」，但實際只有 `case 'echo': return roll(...)` 的接續機率判定；未找到重複施法處理。本次依說明重製，不能稱為舊執行行為逐位一致。

Lab 規則：寶石保證接續，下一個技能完成後獨立擲骰，成功便在一段接續延遲後追加一次真實施放。三級可接兩支線，每支線各自判定一次。追加施放保留原技能等級與該次傷害倍率，選擇附近目標，沒有敵人仍落空施放；不重新判定迴響、不延伸後續節點、不重複消耗或產生物品。實際擊殺照常掉肉，但不回溯觸發原技能後方的擊殺寶石。元素紀錄與共振仍受每輪一次判定限制。

重複事件共用每輪 24 事件上限、暫停時鐘與重置機制。原施法與追加施法的回呼分別冪等，重複回呼不會再生出攻擊；仍有追加工作時不開始新輪。

已接入正常獎勵池、背包條件與觸發率說明；第一份獎勵維持接續寶石。八技能演練第 4 格為三級迴響，方便試用；第 2 格維持增幅。迴響彈道使用既有素材加半透明紫色色調，為暫用美術。

現有為五種原版名稱的可玩重製（機率、命中、擊殺、增幅、迴響），另加試玩接續；其餘十四種原版寶石待移植。原版 22 技能中 8 種仍為暫行行為，其他 14 種待移植。iPad Safari 與完整 20 波平衡未實測。
