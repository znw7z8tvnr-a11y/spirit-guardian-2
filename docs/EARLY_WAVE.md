# 提前開波（Lab）

新增「立即開始／下一波」按鈕與波間倒數。可略過開局五秒或已完成波次的剩餘等待；仍由原本物理更新流程開始下一波，不另複製生成與獎勵邏輯。按下後立即鎖定，連點不能連跳。

僅正常模式可用。有未生成敵人、存活敵人、飛行法術、剩餘連鎖、待吸收血肉、未領獎勵、未確認配置、成長介面、暫停、續玩提示或未完成結算時，一律不可跳過。第20波不可用；不產生第21波。演練不計正常開波。

開波前同步保存最新安全波間；若儲存失敗會保留警告，但不阻止繼續遊玩。戰鬥中重載仍回到最近完成的波間，不冒充完成新的一波。略過等待也略過該段原本的自然回血時間，不另送回血、血肉、物品或刷新。

新增 wave_gate.gd 為可獨立驗證的規則；main.gd 只縮短 rest，不重寫核心生成。新增按鈕放在戰況訊息旁，保留原八個操作鍵的位置與觸控尺寸。

原生 early_wave.gd 測實際前三波、獎勵與配置阻擋、連點、進戰前保存及讀回、剩餘連鎖／飛行／掉肉，以及末波防越界。Web 測試以1倍速真實觸控跑到第四波，驗證橫直畫面、44 CSS像素按鈕、波間重載、獎勵不重領，不注入遊戲狀態。完整報告與實際遊戲截圖在 docs/early-wave；發布狀態以 release.json 為準。
