# 刷新內容保證（Lab）

每次成功刷新，整組三選至少一項的種類／物品／等級內容與前組不同；只有交換順序不算。仍可能看到部分相同物品，也不保證升級、出稀有或每張卡都換。這是獎勵刷新體驗，不是新增稀有度保底。

保留原抽選池、基礎品質權重、技能／寶石／詞條各一項、第一次領獎前接續寶石保證、刷新詞條與Boss獎勵數量。排除完全相同組合會改變連續結果分布，不能稱與舊版機率完全相同。

正常重新抽選最多八次；若仍相同，只從原技能池排除當前技能後選另一種，保留其等級及其他卡。整次操作只扣一次刷新、不發物品、不增加待領機會。異常無替代選項時回復原選項與RNG，不扣次數。刷新後仍由原安全波間儲存保存選項、已用次數與RNG，沒有新增存檔欄位或刪除舊存檔。

reward_reroll.gd 純處理內容識別與替代技能，rewards.gd 保留原發獎流程。原生測試含順序識別、強制重複抽選的有界回退、1000種子抽樣、原三分類／接續保證、成本與詞條；Web測試從真實第三波領獎，以觸控刷新、重載、領物及再次重載檢查不重領。
