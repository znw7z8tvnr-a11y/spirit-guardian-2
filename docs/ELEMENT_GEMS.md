# 元素條件寶石與自動排列修正

新增灼燒、冰凍觸發，來源 V9 各級機率都是 40%／65%／90%。灼燒要求火系實際命中（包含流星），本身不施加持續灼燒。冰凍要求冰系實際命中（包含冰霜新星），或本次實際命中的任一敵人正在緩速；冰系緩速由既有傷害處理套用。

判定採用命中當下的元素與緩速快照，不再於寶石延遲觸發時讀取可能已釋放的敵人物件。範圍法術只判定一次，任一實際受擊目標符合即可；落空、範圍外未受擊的緩速敵人不能提供條件。三級分岔先判定一次，再接續兩支線。保留落空施法，但條件寶石會停止該支線，這與施放型接續寶石不同。

隨機排列會優先選可承接前段元素的寶石，並挑選可供剩餘寶石接續的技能。已知共振排列也使用元素相容檢查；無法組成時保留原配置。不預設敵人已被其他攻擊緩速。手動仍允許跨元素安排，方便搭配實際緩速戰術。

正常獎勵池有八種：七種原版名稱的可玩移植／重製，加試玩接續。第一份獎勵仍提供接續寶石。八技能演練原配置不改，另外把兩顆三級元素寶石放入背包，可手動替換流星後或冰霜新星後的接續寶石；重複載入不重複發放。原版其餘十二種寶石與十四種攻擊技能仍待完成。

新增實際彈道測試覆蓋火球、流星、寒冰、冰霜新星、非冰攻擊命中緩速敵人、元素不符、落空、死亡並釋放後接續，以及十個種子的自動排列。美術為既有暫用寶石圖加色調；iPad Safari、完整二十波平衡仍未實測。
