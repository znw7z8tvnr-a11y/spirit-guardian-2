# 八種前段攻擊寶石

此頁記錄八寶石交付當時的測試與版本。後續迅捷與暴擊條件已加入 Lab，最新規則與驗證見 [FINAL_GEMS.md](FINAL_GEMS.md)。

核對 V9 寶石模組的 ATTACK_GEMS、bonus、maxChildren、ownBoost 及 nextMult：八種攻擊寶石增強所屬前段法術，任何品質都僅一條後續線。它們與增強後續技能的 split／rapid 有不同方向；來源 executeCast 對這八種使用 ownBoost，往下一段傳遞的倍率為 1。

| 寶石 | 一級 | 二級 | 三級 |
| --- | --- | --- | --- |
| 爆破攻擊 blast | +15% | +30% | +50% |
| 雷擊攻擊 bolt | +12% | +25% | +45% |
| 毒蝕攻擊 venom | +10% | +22% | +40% |
| 寒霜攻擊 frostatk | +10% | +20% | +35% |
| 致命攻擊 critical | +20% | +40% | +70% |
| 穿刺攻擊 piercing | +12% | +25% | +45% |
| 廣域攻擊 range | +10% | +20% | +35% |
| 多重攻擊 multi | +15% | +30% | +50% |

Lab 用技能後接的攻擊寶石決定該技能本次直擊倍率，與前一個條件寶石傳入的 next_boost 相乘；後段傷害不繼承本次 own_damage_scale。迴響會重新算一次相同加成，不平方，亦不多走一次後續連鎖。持續中毒固定傷害與已生成守衛的後續攻擊不受這項新直擊加成影響；既有法術增幅對召喚物的快照規則不變。

依核對的來源，這些名稱不另外增加暴擊、毒傷、半徑、穿透或攻擊次數；其已確認效果就是表列的前段傷害加成。「致命攻擊 critical」也不是尚未移植的「暴擊條件 crit」。不改元素類別、不新增共振配方。Lab 保留空打可接續的既有規則，與來源無實際命中就 return 的細節不同。

裝備與連線均限制這八種最多一線；不能把既有雙分岔三級條件寶石直接換成攻擊寶石並保留兩線。隨機排列與已知共振排列仍使用實體物品及原本十格容量。正常掉落池可抽到新寶石，第一次獎勵的接續保底維持不變。

「配置／背包」中新增「攻擊寶石演練」，一次提供八種三級測試寶石，保留原技能演練的全部物品；不在正常開局免費發放。演練總數 40 件，加卸除卡三頁 15／15／11；舊技能演練仍為 32 件。測試配置是奧術→致命→火球→爆破→寒冰→寒霜→雷電→雷擊→奧術，前段倍率為 1.70／1.50／1.35／1.45／1.00，只使用九格。重複載入不複製物品。

背包可比較前段直擊傷害與後接攻擊寶石加成；寶石以新增的自製 attack_gem.svg 共用外型加不同顏色及名稱區分，仍為暫用素材，未達最終美術品質。

原十九種寶石現有十七種暫行版本，還有迅捷 rapid 與暴擊條件 crit 待移植；relay 仍是額外原型物品，不充當十九種之一。22 種技能入口保留，完整原版模組對照、共振效果、二十波平衡與 iPad Safari 實機尚未全數驗收。

本機 Godot 4.6.3 匯入、場景／資源及 1082 項引擎斷言通過，攻擊寶石專屬 106 項。驗證以來源描述解析三級百分比，實際 Projectile／Enemy／CombatResolver 扣血，涵蓋前段倍率、後段不繼承、迴響不平方、血肉與詞條、持續中毒及守衛隔離、單線及替換限制、空打、廣域不擴半徑、物品保留與背包傷害比較。

Linux Chromium 軟體 WebGL 橫直向新寶石觸控測試與原 22 技能／兩類守衛完整回歸皆通過，無頁面或引擎錯誤。實際選取八種新寶石並替換致命為多重，五段施法的前段倍率為 1.5／1.5／1.35／1.45／1.0，下一段傳入倍率皆為 1；數值扣血由獨立引擎測試驗證。未注入遊戲狀態，並非 iPad Safari 實機或完整二十波平衡驗收。
