# M2.1：iPad 觸控與可讀性

獨立分支 `godot/m2-1-ipad`；原 HTML、main 與原 GitHub Pages 入口不變。沿用既有私人 M2 試玩站。

## 實際修改

- 戰鬥按鈕改為至少72個邏輯像素高。直向法術區自動切成4欄，按鈕加寬至196，字級24；橫向維持8欄、字級22。以兩種測試視窗量測主要按鈕實際高度至少44 CSS px。
- 連鎖圖每個節點增加「起點／目標」，先點起點再點目標即可連線。原有拖曳仍可用。提供新增／移除模式、取消、起點選取回饋及錯誤提示。循環、重複、自連線均不接受；失敗不增加復原紀錄。成功連接／移除可復原重做。
- 增加上／下／左／右移動視圖按鈕，不依賴中鍵滑鼠。這只改變視圖，不改動節點座標與配置存檔。
- 點擊目標後延後到輸入處理結束再重建節點，避免刪除正在處理點擊的 Control。
- 可開關「效能」顯示，每半秒更新實測 FPS 與由 FPS 估算的每幀時間。此數字不是 GPU 分析，也不是 iPad 效能保證。
- 中文主題預設字級22；更新內嵌 OFL 字型子集與授權資料。儲存英文ID及 user:// 位置不變。

## 驗證與限制

Godot 4.6.3 Compatibility：18戰鬥＋39模組＋21中文化＋20觸控檢查，共98項。新增檢查涵蓋點選連線、循環拒絕、不污染復原紀錄、移除及復原、關閉取消起點、直橫向配置、視圖移動、效能開關。

實際 Web 匯出測試使用 Linux Chromium 軟體 WebGL、模擬觸控：1180×820與820×1180。操作既有戰鬥與連鎖功能，另外實際點選節點連接／移除／復原／重做、循環拒絕、視圖移動及效能開關。測試紀錄及真實遊戲截圖位於 docs/m2-1/；不是概念圖，也不是 iPad 實機截圖。

尚未驗證 iPad Safari 真機、Safari 工具列縮放、長時間記憶體、VoiceOver及低階裝置流暢度。較小的手機視窗仍待專門適配。連鎖節點仍可多於畫面，使用移動視圖按鈕或捲軸查看；尚未增加多指縮放手勢。效能模式本版只提供量測，未聲稱 FPS 提升。

完整戰局存檔、剩餘法術／共振、Boss招式與正式2.5D美術仍依既有缺口清單進行。此版未刪除原HTML功能或宣稱全部移植完成。
