# 第十七種 Lab 攻擊：毒沼

來源核對 V9 寶石模組、V31.16 法術模組與 V31.30 戰鬥特效模組：swamp 基礎威力 22，命中落點距離嚴格小於 75、最多二十四個目標。選敵沿用 Lab 的選中目標優先、其餘按距離排序，與原陣列順序不同。

來源 ELEMENT 把 swamp 分為 poison，但 executeCast 對底層 hit 仍傳 swamp。本 Lab 依元素表統一為毒系，套用現有中毒：2.5 秒內，每 0.5 秒造成 3 點傷害，共五次；直擊受等級、血肉與詞條加成，中毒每次 3 點維持既有固定數值。這是明確的 Lab 整合選擇，不宣稱原 HTML 毒沼已有完全相同的中毒行為。

重複命中只刷新中毒剩餘時間，不建立額外計時器或疊加多份中毒；狀態傷害不會刷新自己。擊殺寶石仍依本次直擊結果判定，中毒稍後擊殺不會回頭重啟已結束連鎖。毒霧動畫不負責傷害，中毒計時由既有 Enemy／CombatResolver 處理。

接入一至三級獎勵、背包預覽替換、技能演練與連鎖。演練提供二級毒沼，背包第二頁可選。原目標失效保留原落點；沒有受擊者仍顯示無傷害落空特效。多目標只延伸一次連鎖，不額外增加共振配方。

特效包括毒沼底層與最多六個取自真實 hit_positions 的毒霧 Sprite；毒霧緩慢上飄並保留原命中位置資料。特效有最長 2.5 秒的淡出，不代表之後走進區域的敵人會自動中毒，也不是新增常駐毒區。

新增自行製作的 swamp.svg／swamp_haze.svg，皆為暫用美術，未達最終 2.5D 品質。每組最多一個底層與六個毒霧 Sprite，維持四十八組特效上限；尚未進行 iPad Safari 實機效能驗收。

演練二十七件物品全部保留，連鎖仍十格，背包每頁十五張卡。穩定版根目錄仍為八種攻擊，Lab 為十七種暫行攻擊；原二十二種尚有五種待移植，十九種寶石仍有十種待移植。完整二十波平衡、原版全模組對照與正式美術尚未完成驗收。
