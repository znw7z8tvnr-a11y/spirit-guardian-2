# 法術增幅寶石

原版 V9 `split` 名稱是法術增幅，其實際效果為後續技能威力 +10%／20%／35%，不是新增分流。Lab 新增此第四種原版寶石，另保留試玩接續寶石；原版其餘十五種仍待移植。

本次明確採用「下一個技能」直擊加成：寶石保證接續，三級照一般三級寶石規則最多接兩條線；兩支線各自取得一次加成，後續寶石不繼承已消耗的加成。與法術等級、血肉攻擊與詞條加成相乘；範圍直擊包含在內，固定中毒跳傷與共振另計。落空仍完成這次施法並消耗加成，不保留到下輪。

正常獎勵納入五種寶石隨機候選，第一份獎勵仍提供接續寶石。八技能演練首顆三級寶石改為增幅，方便直接試用；舊連鎖演練維持接續配置。背包說明數值與條件，圖示採黃綠色調的暫用寶石圖。

新增引擎測試驗證各級數值、分岔隔離、單次消耗、四次實際彈道命中的總傷害與無重複回呼。網頁測試會從觸控介面確認說明，並檢查實際施放軌跡帶有加成。Safari／iPad 與完整二十波平衡仍未實測。
