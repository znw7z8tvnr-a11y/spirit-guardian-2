# 第十三種 Lab 攻擊：火花術

核對 V9 寶石模組、V31.16 法術模組與 V31.30 戰鬥特效模組：spark 基礎威力 13，選取落點距離嚴格小於 165、最多六個目標。每個受擊者取得完整技能傷害，不套用 Lab 普通火球／閃電的鄰近波及倍率。選敵沿用 Lab 的選中目標優先、其餘按距離排序，不是原陣列順序的逐位重現。

來源差異：原模組的 ELEMENT 表把 spark 分為 lightning，但 executeCast 對底層 hit 仍傳 spark 字串；V31 視覺演出則使用較小型的火花外形。本 Lab 以元素表整合為雷系命中與連鎖元素，背包明示雷系，不因名稱「火花」自動觸發灼燒寶石。這是明確整合選擇，並非完整逐位移植。

接入一至三級獎勵、背包預覽替換、技能演練與連鎖。演練提供二級火花術。目標消失保留原落點，沒有受擊者依然呈現落空特效。一次六目標結算只推進一次連鎖，不增添額外傷害或共振配方。

命中結果新增 hit_positions，記錄實際受傷目標當下的位置；火花爆發 Sprite 只出現在這些位置，最多六個，避免把沒有命中的敵人畫成受擊。落空則在原落點顯示一個無傷害爆發。所有位置均由實際傷害結果產生，不由動畫捏造命中。

新增自行製作的分層火花 SVG Sprite，屬暫用美術；未達最終 2.5D 品質。最多四十八組特效，每組最多六個子 Sprite，尚未完成 iPad Safari 實機效能驗收。

連鎖保持十格，演練二十三件物品全部保留；背包每頁十五張卡，第二頁可選火花術。穩定版根目錄仍為八種攻擊，Lab 為十三種暫行攻擊。原二十二種尚有九種待移植，十九種寶石仍有十種待移植。完整二十波平衡、正式美術與完整模組對照尚未驗收。

本機驗證：661 項 Godot 4.6.3 引擎檢查全部通過，其中火花術二十二項涵蓋真實傷害、嚴格半徑、六目標上限、完整傷害倍率、雷系條件、一次連鎖延伸、真實命中位置、受擊 Sprite 位置、目標失效保留落點及無怪落空。首輪測試發現火花術誤入既有範圍分支，已修正為獨立的 165／6 規則；落空測試也把其他敵人移到新範圍外，修正後完整回歸通過。

完整瀏覽器回歸包含舊技能、冷卻、倍速與月刃，再以背包替換火花術；橫向和直向均各施放一次並命中一次，沒有頁面或引擎錯誤。上線包另以分段 WASM 載入器驗證兩向裝備、施放、命中，以及特效仍存在時暫停。spark-package 圖片為實際遊戲測試截圖，不是概念圖，暫用美術並未作正式品質驗收。

Linux Chromium 軟體 WebGL 測試不能替代 iPad Safari 實機效能與完整二十波平衡驗收。來源比較見 docs/spark-spell/source-comparison.json；部署與線上檔案核對另見 release.json 和 live-assets.json。
