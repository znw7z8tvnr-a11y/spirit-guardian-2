# 敵人可讀性與標籤數量上限（Lab）

本輪為顯示層調整，未修改怪物生命、傷害、移速、治療、護盾、鼓舞、波次、獎勵與法術結算。

原本每隻敵人建立 Label，部分角色每個物理步驟重設文字；四十隻敵人會有四十個頭頂標籤，密集時互相遮蓋。現在移除敵人身上的 Label，交由 `enemy_presentation.gd` 顯示層建立六個可重用螢幕標籤，每 0.2 秒 UI 更新時重新配置，僅在文字有變時寫入。

優先處理仍在蓄力的敵人，依剩餘時間與固定 ID 排序，每個敵人最多一個標籤；同類蓄力最多兩個代表、待機同類最多一個，其餘由固定敵情列計數。同一敵人同時施放靈彈與治療時，標籤選最快完成的一項，固定敵情列仍會計入兩種動作；敵情列優先列出靈彈，再合併三類倒數，未列類別顯示額外動作數。正數倒數採向上取一位小數，避免仍在蓄力卻顯示 0.0 秒。

標籤嘗試九個位置，避開已放置矩形並限制在 HUD 與操作列之間；放不下、離開可顯示區或畫面太小時隱藏世界標籤，固定敵情列保留。細引線指向原敵人，滑鼠及觸控事件穿透，不遮擋操作；編輯、成長與獎勵介面開啟時隱藏戰場標籤。

配置／背包新增「四十隻敵人演練（不計獎勵）」：四十個有 Sprite 動畫、AI、受擊與支援能力的真實戰鬥單位，沿用演練隔離，不發放掉肉或波次獎勵，不保存共振紀錄。不是完整二十波通關。

驗收包括實際 Control 矩形、視窗邊界、重複敵人排除、暫停文字寫入不增加、最小視窗降級、真實 HP／計時器不受顯示模組改動，以及 Chromium 直橫向四十隻戰鬥與觸控。測得 FPS 只記錄於報告，沒有相同條件的前後基準就不宣稱提升百分比。

上限是六個標籤、每個候選至多九次位置嘗試；不是保證所有敵人同時有文字。素材仍為暫用，iPad Safari 實機與長時間滿載效能尚待驗收。正式命名、成就、完整二十波平衡與全部怪物詞條仍不在本輪完成範圍。
