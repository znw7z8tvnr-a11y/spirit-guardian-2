# 第九種 Lab 攻擊：穿透射線

V9 的 pierce 基礎威力為 24，選取與目標垂直距離小於 38 的水平帶，最多 8 個敵人，傷害映射為雷系。本次保留數值、嚴格邊界、水平帶與上限；選敵調整為優先保留選中目標，再依距離與實體 ID 排序，避免上限把選中目標排除。並非逐位重現舊陣列順序。

這與現有聚焦光束不同：光束沿本段施法方向有限距離穿透；穿透射線命中目標所在橫列的左右兩側。原目標消失仍保留原橫列，按實際倖存者結算；沒有橫列受擊者就是落空。多個受擊者只推進一次連鎖，命中、擊殺、緩速與殘血快照沿用實際結果。

新增直線引導投射與覆蓋戰場的水平光帶 Sprite，顯示高度對應 76 世界單位。圖像重用有界的雷電圖集與既有分層光束素材，屬暫用特效，未達最終美術品質。

正常 Lab 獎勵與背包支援一至三級，傷害沿用技能等級、血肉與詞條倍率。演練額外提供二級穿透射線供替換；按鈕改名「技能演練」，原配置與八種舊技能保留。主專案穩定版仍只宣告原八種可玩技能；Lab 使用獨立九種清單。新增的是原 22 種中的第九種暫行行為，其餘 13 種仍待移植；十九種寶石中的十種仍待移植。

引擎驗證涵蓋水平兩側、38 邊界、八目標上限、等級與血肉傷害、實際多目標連鎖只延伸一次、目標釋放後保留橫列，以及無受擊者落空。網頁透過觸控預覽、替換並在時序連鎖內實際施放穿透射線。Safari／iPad 實機、完整二十波平衡與完整戰局存檔未完成驗收。
