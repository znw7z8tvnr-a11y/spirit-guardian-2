# Lab 連鎖音效接入（2026-11-25）

新增 audio_controller.gd 場景子節點，以訊號觀察施法與共振，未覆寫 main.gd 的攻擊或傷害函式。既有事件列新增「音效：關／開」觸控按鈕；每次載入預設關閉，不寫入存檔。有效連鎖即使沒有目標也可發聲；過期連鎖事件忽略。

22 種技能依元素送入既有四種短音色或備用音，共振使用奧術提示音。這不是 22 種獨立音效或完整音樂移植，仍為暫用合成提示音。沿用 90ms 節流、八個播放器上限及波形快取，密集共振可能與其他提示合併。

Godot 4.6.3 匯入、Lab 解析及六組相關測試共 153 項通過；原生結果在 native/。包含實際開局施法訊號接線、22 種鍵值音色路由、過期事件、重複綁定、預設靜音與存檔快照不變。22 種路由測試直接呼叫觀察器，不代表全部技能均經瀏覽器戰鬥驗收。Python 驗證選測規則 27 項通過。

browser/ 與 m2-regression/ 記錄 Lab、原 M2 橫直向 Chromium 觸控測試：預設靜音、開啟後非零 Web Audio 訊號、關閉回靜音、再次開啟及 44 CSS px 觸控目標，無頁面或引擎錯誤。分析器量測音訊圖，不等同實機喇叭或真人聽感；未強制解除 autoplay 限制。iPad Safari、背景音訊中斷與實機延遲尚未測試。
