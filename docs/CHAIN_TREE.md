# 連鎖樹介面試驗

此版只更新獨立 Chain Lab，保留原 HTML 與 M2.1 預設場景。

- 十格改為實際圖示節點與方向連線。圓形技能、菱形寶石圖示、編號、等級與選取框。
- 依實際圖資料排列分岔；未裝備空格仍可點選。顯示魔杖用量及選中物品名稱。
- 保留背包替換、起點／連線／斷線、隨機排列、共振紀錄與未知配方限制。
- 操作：配置／背包 → 點節點 → 下拉選物品 → 替換此格。連線時先選起點並按「設為起點」，再選終點並按「連到此格」。
- 戰鬥中的血肉城牆、自動／手動強化及 1／2／4／8 倍速不變。

美術：法術使用既有 legacy 素材；寶石是本次自製暫用 SVG（依 LICENSE-GODOT-CODE.md 授權），不是最終美術。此版先以橫向連鎖圖呈現，尚非參考圖的直式拖曳編輯器。背包仍採下拉選單，完整圖示背包與拖放待辦。

驗證記錄在 docs/chain-tree/；畫面 PNG 均為實際 Godot Web 執行截圖。Linux Chromium 軟體 WebGL 觸控模擬不代表 iPad Safari 實機測試；二十波全程平衡與完整技能數量尚未驗收。
