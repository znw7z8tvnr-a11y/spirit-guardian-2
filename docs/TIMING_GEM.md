# 時序寶石：依模擬時間與實體物品冷卻

原版 V9 為每顆寶石記錄最後成功時間，一至三級的間隔為 3／2／1 秒。Lab 首次立即可用；技能施放後會判定，落空也能接續。冷卻中結束當次支線，不排隊、不在稍後補放。三級分岔只消耗一次冷卻，然後接續兩支線。

冷卻使用連鎖模擬時鐘，隨遊戲倍速推進；暫停、配置、血肉成長與獎勵介面會停止時鐘。期限以實體物品 ID 保存，移動同一顆、斷線重連或重新配置不會洗掉；另一顆實體寶石獨立計時。既有冷卻不因等級變動縮短，下一次成功才採用新等級。重新開局建立新模型，清除舊冷卻。

戰鬥顯示「冷卻中 X 秒」，背包顯示目前剩餘時間；顯示值向上取一位小數，避免尚未就緒卻顯示零秒。判定紀錄包含模擬時間及剩餘冷卻，區分條件、機率與冷卻失敗。

已加入正常獎勵與演練背包，演練提供一級（3 秒）便於觀察。原八技能配置不變。現有九種原版名稱的可玩移植／重製，加試玩接續；其餘十種寶石、十四種攻擊技能仍待完成。

引擎驗證涵蓋精確期限、換格保留、獨立物品、重開局、暫停與各介面、真實彈道接續與攔截、三級分岔及空場收尾。網頁從觸控配置建立兩技能連鎖，觀察實際冷卻失敗、暫停不倒數，並在八倍速檢查成功間隔。美術為暫用素材；iPad Safari 實機、完整二十波平衡與完整戰局存檔仍未完成驗收。
