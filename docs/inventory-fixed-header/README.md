# 背包操作列與物品捲動

Lab 背包的返回、確認、比較說明、分類與換頁操作留在上方；下方物品區獨立捲動。換頁時物品區回到頂端，保留既有翻頁取消隱藏候選、關閉取消預選及實體物品驗證。極小畫面若連操作區也放不下，外層捲動仍可使用，避免內容被裁掉。

修改 inventory_view.gd、inventory_ui.gd 與 test_inventory_filters_web.py，沒有改動戰鬥數值、物品數、取得順序、連線、存檔、字型或原 HTML。

原生測試確認短背包真的有物品溢出且卡片移動，返回／確認保持原位，換頁回到頂端。Godot 4.6.3 匯入及 Lab 解析通過，七組相關測試合計 209 項檢查通過；版面與觸控細節修正後僅重跑受影響的 inventory，其他套件按依賴驗證，沒有重跑整個戰局。Python 選測與錯誤處理 20 項通過。

瀏覽器測試除既有橫直向觸控替換，也在 1180×600 短橫向使用 Chromium CDP touch drag 驗證卡片移動、返回／確認／分類位置不變，且持有物與裝備不因拖曳改變。實際結果以 browser-fixed-header.json 為準，未產生該檔時不得視為通過。截圖為實際 WebGL 遊戲。

此輪僅局部驗收，沒有完整 20 波、全部技能或 iPad Safari 實機測試；美術仍是既有暫用素材。尚未發布至線上試玩站。

物品區補上獨立垂直觸控拖曳：12 邏輯像素內的小移動保留點選行為；拖曳成立後取消卡片按壓，防止放開時誤選。只追蹤起始手指，放開或隱藏介面後結束追蹤。此處不宣稱新增慣性捲動或 Safari 實機支援驗收。
