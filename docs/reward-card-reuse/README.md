# 獨立優化：獎勵卡說明重用

2026-11-26，在最新預警標籤及試玩版來源之後，獨立修改 reward_view.gd。每張獎勵卡只保存 kind／key／level 的值簽章；三張卡的描述只在對應值變更時重新產生。鎖定與解鎖仍更新按鈕可用性、刷新次數和摘要，不重產生相同技能／寶石說明。描述實際相同時也不重寫按鈕文字。

快取固定為三個簽章，不保存可變 offers 字典引用，不隨獎勵次數增加。卡片重排、等級改變、換成另一項獎勵會更新；相等的深複製資料可以重用。沒有修改抽獎、刷新、掉率、亂數、存檔格式或戰鬥程式。

Godot 4.6.3 匯入與 Lab 解析通過，rewardinput 17／touch 20／reroll 14／rewards 26／checkpoint 36，共 113 項相關引擎檢查通過。Python 選測規則 27 項通過。新增測試覆寫實際 description 方法計數，驗證 25 次相同模型訊號不重算、原字典原地改等級、深複製、重排及還原。原有防連點、刷新、最後一項領取與存檔回歸保留。

這是消除重複 UI 工作，尚未量測 iPad FPS、記憶體或真人操作感；不宣稱全面效能提升。Web 局部結果與交付記錄另見本目錄；不重跑完整 20 波／全部技能。最新線上試玩版、舊 HTML 與整合標記維持原狀，未把這批自動發布。
