# 連鎖戰鬥試驗室 V1

分支 `godot/chain-lab-v1`。此版驗證手感，不是完整 Roguelite。原 HTML、main、Godot 預設 M2.1 場景與已部署的 M2.1 根入口保留；試驗網址另放 `/lab/`。

## 怎麼玩

1. 開局只有一級奧術飛彈與10格空間，會自動攻擊。
2. 點「載入試驗配置」，取得明確標示的測試用物品並開啟背包。這不是正式掉落。
3. 預設配置：01奧彈 → 02三級接續寶石，分至03火球與04冰槍；冰槍 → 05寶石 → 06雷擊，火球 → 07寶石 → 08奧彈。09／10格留空。三級火球另留在背包供替換。
4. 點格子查看背包可用物品，再選「替換此格」。同一件不能重複裝備；替換下來物品回到背包。更換類型前需先移除不相容連線。起點必須是技能。
5. 點起點格、「設為起點」、目標格、「連到此格」。技能與寶石必須交替；普通寶石只有一線，三級寶石最多兩線。分岔不增加10格容量。可隨機合法排列已有物品。
6. 返回戰鬥，切換標準／慢速／快速，觀察下方逐段紀錄、拋物線法術與分岔。暫停或開背包時，怪物、連鎖及在途法術都停止。

## 已實作的戰鬥規則

- 一把魔杖、一輪連鎖；前一輪尚未完成時不開始下一輪。
- 場地背景展開至原快取1.45倍；怪物出生距離由原橢圓560×245改為820×410，攝影機0.72倍觀察更大的場域。塔補償攝影機縮放，避免跟著縮小。
- 標準每輪至少3.8秒、每個節點間隔0.32秒、法術飛行0.62秒。慢速5.2／0.48／0.85，快速3.2／0.20／0.45。這是初始調校值。
- 接續寶石1～3級觸發率85%／93%／100%；三級可分岔。技能1～3級傷害倍率1／1.55／2.10。
- 目標死亡後，在最後命中位置480世界單位內尋找活怪接續；在途法術與等待中的寶石都處理死亡轉移。無附近目標才結束，不跨整張地圖傳送。
- 同一輪、同一魔杖的所有分岔共用「實際命中元素」集合；背包、未連通或未觸發技能不計。集齊指定三元素後，每輪只判定一次，成功率30%，成功後冷卻8秒。
- 使用來源既有4種三元素共振。首次成功觸發才收錄；未知配方不預覽。發現獨立存於 user://chain_lab_book.json；已知共振排列只在已解鎖且持有試驗套件時啟用。此版自動配方排列只提供套件具備的火冰雷配方。
- 普通、快速、裝甲、精英及沿用Boss行為；降低接近速度與塔傷害，區分血量、移速。每5波一Boss，20波結束。尚未完成整局20波真人平衡驗證。

## 檔案及匯入

實作在 godot/experiments/chain_lab/，不覆寫原 modules/chain_graph 或 scripts/main.gd。

Godot 4.6.3 Compatibility。庫內預設Play仍為M2.1；可直接執行 experiments/chain_lab/main.tscn。Web使用獨立「Web Chain Lab」preset，以chain_lab feature選場景，輸出export/lab。

SpiritGuardian-Godot-ChainLab.zip 是可直接匯入的完整專案，打包時只把project.godot的預設場景切成試驗室，方便iPad直接Play；所有原M2.1場景仍在。SpiritGuardian-Web-ChainLab.zip 是HTTP(S)部署用，不能直接在「檔案」App打開HTML。

## 驗證

98項既有檢查加30項實驗檢查，共128項。包含10格與實物庫存、交替、分岔上限、升級替換、共振一次判定及冷卻、跨分岔元素、死亡保留兩支線、無附近目標停止、隨機合法配置、Boss波與20波終止。

實際60秒固定步進戰鬥（固定測試種子、為覆蓋路徑將共振率設100%）到第3波、18擊殺、41次技能命中、3次共振及9次目標轉移，水晶100。這是正確性測試，不代表正式30%共振率下的平衡、真實幀率或長跑表現。

Linux Chromium軟體WebGL橫1180×820／直820×1180，實際觸控測試初始奧彈、配置／背包、禁止技能直連、唯一物品隨機排列、返回、節奏、暫停及連鎖命中。實際遊戲截圖與報告位於docs/chain-lab/，不是概念圖。

待完成：第二把魔杖、擴格道具、詞條、每三波／Boss隨機獎勵及保底、完整可視化連線圖、完整紀錄書整理、戰局存檔、完整20波平衡、iPad Safari真機與正式美術。試驗版不表示這些已完成；M2.1既有系統留在原入口。
