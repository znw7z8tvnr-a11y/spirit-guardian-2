# 第十四種 Lab 攻擊：雷電風暴

核對 V9 寶石模組、V31.16 法術模組與 V31.30 戰鬥特效模組：storm 基礎威力 35，選取落點距離嚴格小於 155、最多二十四個目標。每個目標取得完整傷害，動畫中的閃爍不再造成傷害或推進連鎖。

來源 ELEMENT 表把 storm 分為 lightning，executeCast 對底層 hit 則仍傳 storm。本 Lab 與火花術一致，使用元素表整合為雷系命中與連鎖元素。原 V31 特效是八分支閃電；本版改製為雲層與最多八道落雷 Sprite，屬明確視覺重製，不是原畫逐位還原。

接入一至三級獎勵、背包預覽替換、技能演練與連鎖。演練提供二級雷電風暴，背包第二頁可選。保留目標失效後原落點結算與落空效果；一輪範圍傷害只延伸一次連鎖，沒有新增持續雷區或其他共振法術。

earth／wind／sword／spark／storm 的嚴格半徑與目標上限整理為單一資料表，統一使用選中目標優先、其餘按距離的選敵流程。既有隕石與冰霜新星維持原 Lab 的包含邊界行為。選敵排序與原 HTML 陣列順序有差異，已明示為 Lab 整合選擇。

落雷位置取自真實 hit_positions；最多顯示八個實際受擊位置，其餘目標的傷害仍正常結算。這是特效數量的效能取捨，不表示最多只傷害八個敵人。落空時顯示原落點的一道無傷害落雷。每組最多一個雲層與八個落雷子 Sprite，全場維持四十八組特效上限，未作 iPad 實機效能驗收。

新增自行製作的暫用雲層與閃電 SVG Sprite，未達最終 2.5D 美術品質。演練二十四件物品全部保留，背包每頁十五張卡，連鎖仍為十格。穩定版根目錄維持八種攻擊，Lab 為十四種暫行攻擊；原二十二種仍有八種待移植，十九種寶石仍有十種待移植。完整二十波平衡、原版全模組對照及 iPad Safari 實機尚未完成驗收。

本機驗證：687 項 Godot 4.6.3 引擎檢查全部通過，其中雷電風暴二十六項涵蓋真實傷害、嚴格範圍、二十四目標上限、命中位置、雷系條件、單次連鎖延伸、八道落雷視覺上限、真實位置錨點、無目標落空，以及閃爍不重複傷害。視覺上限測試使用實際二十四目標傷害結果產生的 hit_positions。

完整瀏覽器回歸含舊技能、冷卻與倍速，再由背包替換雷電風暴；兩種方向各施放一次並命中一次，沒有頁面或引擎錯誤。上線包另測分段 WASM 載入，兩向均成功裝備、命中並在雲層／落雷特效存在時暫停。storm-package 圖片是實際遊戲測試截圖，不是概念圖；暫用美術仍未作正式品質驗收。
