# 獨立優化：預警標籤顯示狀態重用

在 2026-11-26 整合版之後獨立修改 enemy_presentation.gd。原本每次刷新先隱藏所有池內標籤，再顯示有配置的位置；改為已顯示的標籤保持顯示，刷新結束只隱藏不再需要的尾端標籤。畫面過小時仍清除全部標籤。位置、文字、顏色及連線仍依當前敵人更新，候選順序、數量上限、碰撞避讓及戰鬥計時不變。

原生 readability 90 項、enemytactics 41 項，共 131 項通過；另含匯入、Lab 解析，Python 選測規則 27 項通過。新增測試觀察實際 Control.visibility_changed：25 次相同刷新不產生顯示／隱藏事件；空戰場、恢復敵人、過小畫面及重複空狀態都維持正確可見性與配置，不以自訂計數器替代事件證據。

這是減少重複 UI 狀態變更，沒有量測實機 FPS 增幅。美術仍為暫用，iPad Safari 尚未驗收。後續 Web 局部回歸與交付檔案記錄在本目錄，不重跑完整 20 波或宣稱全部系統重新驗收。

保持獨立提交與標記，未移動 lab-integrated-2026-11-26，也未發布線上站或修改原 HTML。
