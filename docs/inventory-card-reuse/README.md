# 獨立優化批次：背包物品卡重用

重開背包或切換要編輯的格位時，重用既有物品按鈕與 TextureRect，不再刪除並重建整批物品卡。新增物品只建立缺少的卡；物品減少時從卡片表與容器移除多餘卡，排程釋放，保留目前持有物品的順序。

每次開啟仍重新計算目前格位、使用中／背包可用文字、分類、預覽與裝配驗證。種類或 key 變更時更新圖示與色調，等級變更時更新文字；技能不會殘留先前寶石色調。物品卡的回呼只在建立時連接一次，重開時清除舊按壓與手勢，原有關閉取消預選及翻頁防誤裝保留。

不快取物品所有權或裝配決策，不改物品、掉率、戰鬥、連線、存檔或字型。修改 inventory_view.gd 與 inventory_ui.gd，沿用既有局部驗收依賴。

Godot 4.6.3 匯入、Lab 解析與 inventory 32／inventoryfilters 35／tree 75／touch 20，共 162 項相關檢查通過。新增測試包含 20 次重開後的真實按鈕／圖示 instance ID 相同、回呼數量不增、換格位及裝備後文字更新、增加一件只新增一卡、種類／圖示／色調／等級變更、移除物品後殘留按鈕事件被拒絕。Python 選測與錯誤處理 24 項通過。

Web 結果以 browser-card-reuse.json 為準，未產生報告時不能當成已通過。執行橫直向的真實背包／明確標示演練背包分類、分頁、替換、取消、重開、觸控拖曳與背景樹遮擋測試；不重跑完整 20 波或全部技能。

這批驗證減少 UI 節點重建，沒有量測 iPad FPS。iPad Safari 真機及正式美術未驗收。獨立保存，不移動舊版本標記，也不更新線上試玩站。
