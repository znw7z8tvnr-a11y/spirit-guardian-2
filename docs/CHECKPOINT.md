# 波間存檔與續玩（試驗版）

完成一波、敵人／飛行法術／連鎖／待吸收血肉全部結清後，自動保存最近的安全波間。重新整理頁面後，先顯示「繼續波間進度」與「重新開局」；不會直接開始戰鬥。

保存波次、核心與血肉城牆、本局成長、持有技能／寶石及十格連線、已領獎勵、尚未領取的抽選與剩餘刷新次數、倍速／節奏、冷卻、存活召喚物及四組亂數狀態。領獎、刷新與配置變更會更新安全波間，因此重新整理不會重領同一份獎勵或增加免費刷新。召喚物讀回原傷害與剩餘壽命，不重新套用召喚增幅。

## 範圍與限制

- 戰鬥中中斷會回到最近波間；第一波尚未完成時沒有續玩點。不是即時戰鬥快照。
- 訓練／試驗配置不覆寫正式局進度；明確重新開局、正式局勝負結算會清除本局進度。
- 一份本機進度與上一份備份，無雲端同步。換瀏覽器、換網址、清除網站資料或瀏覽器回收儲存空間都可能無法續玩。
- Web 使用 Godot 官方 `force_fs_sync()` 寫入瀏覽器持久儲存；寫入為非同步，不保證突然斷電或作業系統強制終止前最後一次變更都完成。
- 獨立檔案 `user://chain_lab_run_v1.json`；原版 HTML、M2、舊配置檔與共振紀錄書不混用。紀錄書讀回時合併已發現配方。
- 格式版本、SHA-256、型別、有限數值、獎勵來源與節點圖均先檢查，再讀回。損壞主檔可回退備份；無法辨識版本保留至玩家明確重新開局。檢查碼用於偵測損壞，不是防作弊服務。

## 修改與驗證

核心檔案：`checkpoint_store.gd`（資料與寫入）、`checkpoint_view.gd`（續玩介面）、`main.gd`（安全波間與 UI 整合）。既有測試停用持久續玩，避免測試局互相污染。`tests/checkpoint.gd` 驗證實際第三波、領獎／刷新、重載、亂數還原、召喚物、損壞資料與備份；`tools/test_checkpoint_web.py` 以橫直畫面真實觸控、同來源網頁重新整理驗證持久保存。

本輪結果與實際遊戲截圖存於 `docs/checkpoint/`；自動驗收不代表 iPad Safari 實機驗收或最終美術品質。本機 Godot 38 組測試共 1,300 項檢查通過；Chromium WebGL 橫直向皆通過第三波實際戰鬥、刷新後重載、領獎配置再重載與明確重新開局。完整遠端回歸及發布狀態以本輪交付紀錄為準。
