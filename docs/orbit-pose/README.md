# 獨立優化：旋轉法球共用旋轉計算

orbit_fx.gd 將五個固定相位及單位方向在建立時預先計算，動畫更新共用一組 sin／cos 與旋轉基底，再套回原 60×35 橢圓。原本每次位置更新五組 sin／cos（十次），改為一組（兩次）；建立時仍需計算五個初始方向。多保存五個相位及五個向量，每個有限生命特效自行持有，不是無上限快取。

保留五顆光球、符文、旋轉速度、0.9 秒壽命與淡出公式。沒有修改傷害、選敵、範圍、連鎖或存檔；不是把旋轉法球改成原版永久被動軌道。只減少重複三角運算，沒有實機 FPS 增幅數據。

Godot 4.6.3 匯入及 Lab 解析通過，orbit 29／chainlab 30／touch 20，共 79 項相關引擎檢查通過；Python 選測規則 30 項通過。129 個時間點×5 顆，共 645 個位置樣本對照凍結舊公式，誤差小於 0.0001 世界單位，同時核對光球角度、符文旋轉與淡出。另由真實場景 process_mode 暫停／恢復，驗證年齡和五顆位置凍結、恢復後前進。既有有限壽命、單次傷害、落空與連鎖測試保留。

新增只操作旋轉法球的 Web 局部流程，透過明確標示的技能演練物品，實際觸控裝備、施放及暫停／恢復。結果與交付資訊另記。本輪不重跑整局或全部技能；部分美術仍為暫用，Safari 真機與裝置效能尚未測試。線上試玩站、原 HTML 與之前版本標記保持不變。
