# 殘血追擊與連鎖判定提示

原版 V9 實際程式是 `target.hp <= target.maxHp * [0.25,0.40,0.55][q]`，所以邊界相等也成立。Lab 依命中後的真實生命比例快照判定：一至三級不高於 25%／40%／55% 即接續，沒有額外機率。剛擊殺的敵人比例為零，仍能保留接續；落空不能觸發。

範圍法術以本次實際受擊敵人的最低比例判定一次；範圍外殘血敵人不計。護盾吸收後仍以真實剩餘生命判定。延遲毒傷或其他後續攻擊不回溯修改這份快照。三級依既有規則最多分岔兩支線。

新增戰鬥提示與節點色調：接續成功／條件未滿足／機率未觸發。逐次判定紀錄保存原因及生命比例，避免把機率失敗當成連線錯誤。自動排列若有接續、增幅或迴響寶石，優先保留這類開局；其他位置仍保留隨機性，並檢查元素相容。

已納入正常獎勵。八技能演練額外將三級殘血追擊放入背包，與兩顆元素寶石一樣不自動覆蓋既有配置；可手動替換。第一份獎勵仍提供接續寶石。現有為八種原版名稱的移植／重製，加試玩接續；其餘十一種原版寶石、十四種攻擊技能仍待完成。

驗證包含門檻正好相等與略高、實際彈道與節點接續、擊殺後釋放、落空、實際範圍波及、未受擊殘血敵人、護盾吸收、機率失敗提示，以及十種種子的可靠開局。美術仍為暫用色調素材；iPad Safari 實機、完整二十波平衡與完整戰局存檔未完成驗收。
